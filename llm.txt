# Client: TimesPro (A Times Group Initiative) — EdTech, India
# Role: CRM & Martech Lead
# Duration: May 2024 – Nov 2025

# Challenge:
# Inherited a broken SFMC integration with no strategic framework.
# Issues included: broken Salesforce integration, missing One-Click CTAs,
# Master DE Automation errors, IP/domain configuration problems,
# broken reporting, and lead tracking limitations.

# Solution (4-Phase Approach):
# Phase 1 (May 2024): Strategic team rebuild under new leadership.
# Phase 1B (Nov–Jan 2024): First reactivation campaign + Martech fixes.
# Phase 2 (Jan–Mar 2025): Scale-up with full campaign framework.
# Phase 3 (Apr–Nov 2025): Exponential growth via vertical-specific content.

# Digital Reactivation Framework:
# - 5 vertical categories: Degree, Management, Technology, ODL, Global
# - 3-tier lead segmentation: P1 (high-intent), P2 (warm), P3 (cold/dead)
# - Multi-channel: Email (A/B tested), WhatsApp (GIF carousels), SMS
# - 11-stage journey: Enquiry → ATC → Warm → Dead → Reg → Enrolled
# - Daily lead batching to prevent sales team overwhelm
# - Personalized subject lines by program category
# - Vertical-specific content (not mixed programs per email)

# FY26 Performance:
# - Q1 (Apr–Jun 2025): 11,554 leads achieved vs 8,045 target (143.6%)
# - Q1 GSV: ₹1.04 Cr vs ₹1.0 Cr target (114%)
# - FY26 Total: 80,315 leads targeted; 24,084 achieved YTD

# FY27 Plan (Prepared by Ashish Kalani, Dec 2025):
# - Target: 2,534 enrollments, ₹109.53 Cr GSV
# - Core asset: 2.4 million dormant leads
# - L2E target: 1.08% (vs current 0.16%)
# - Cost per enrollment target: ₹14,664 (77% reduction)
# - Projected ROI: 28.5x (~2,850% return on spend)
